# 원본 디자인을 보존한 AI 팝업

기준 화면: https://roombap-hotel-qr.tjdqls3863.chatgpt.site/

메인 화면과 온보딩, 음식 사진·이모지, 카드, 기존 메뉴·주문 화면은 기준 사이트의 공개 HTML·CSS·JavaScript·이미지를 사용합니다. `style.css`와 `app.js`를 포함한 원본 디자인 파일은 수정하지 않았습니다. 파일 해시와 메인 HTML 해시를 `design-baseline.json`에 보관하고 `node scripts/check-design-baseline.mjs`로 확인합니다. 호스팅 제공자가 응답에 자동 삽입한 Cloudflare 보안 스크립트는 로컬 소스에서 제외했습니다.

이번 추가 범위는 오른쪽 아래 작은 AI 버튼과 화면 중앙 팝업입니다. 팝업에는 자연어 메뉴 추천, 한국 유행 음식 알아보기 두 탭을 유지합니다. 영어 표기는 `Explore K-food trends`입니다. 유행 음식 소개는 저장된 관광 자료와 출처를 사용하는 기존 기능이며 실시간 인기 순위를 집계하지 않습니다.

AI UI와 원본 화면 사이의 연결은 `public/ai-bridge.js`, 팝업 동작은 `public/ai-dialog.js`, 위치와 팝업 스타일은 `public/ai-dialog.css`로 분리했습니다. 추천 로직·모델·식이 조건은 이번 변경에서 수정하지 않았습니다. 원본 사이트에 새로 추가된 매장·메뉴 전체와 AI 서버 카탈로그를 동기화하는 작업은 이번 디자인 변경 범위에 포함하지 않았습니다.

## 로컬에서 보기

Node.js 24를 기준으로, 프로젝트 폴더에서 실행합니다. 아래 미리보기는 별도 npm 패키지 설치가 필요하지 않습니다.

```powershell
node --env-file-if-exists=.env scripts/preview-local.mjs
```

http://127.0.0.1:8793/ 에서 확인합니다. AI를 실제로 호출하려면 `.env.example`을 참고하여 로컬 `.env`에 본인 키와 사용 가능한 모델을 설정합니다. 키는 서버에서만 사용하며 Git에 포함하지 않습니다. 키가 없어도 원본 화면과 팝업 디자인은 확인할 수 있습니다.

이 작업은 Git 공유용 로컬 작업본에 반영했습니다. 기존 공개 사이트는 배포하거나 변경하지 않았습니다.

이후 1단계에서 메뉴 데이터 동기화를 완료했습니다. 원본 렌더링 코드·스타일·사진을 유지하며 데이터만 공통 원본에서 불러옵니다. 자세한 내용은 [메뉴 동기화](CATALOG_SYNC.md)를 참고합니다.

## 확인 결과

원본 디자인 파일 153개와 메인 HTML 보존 검사를 통과했습니다. 데스크톱, 390px·320px 화면에서 팝업 위치, 키보드 초점, 닫기, 하단 메뉴와의 간섭을 확인했습니다. 실제 자연어 추천에서 기존 메뉴·옵션 화면으로 이동하는 흐름과 두쫀쿠 소개의 출처 표시도 확인했습니다. 오류 응답에서 임의 메뉴 카드가 생기지 않는지 확인했습니다.

화면 예시와 브라우저 확인 결과는 [design-review](design-review/)에 보관합니다.
