# 설문·AI 사용 안내 문구

2026-10-30 로컬 수정입니다. 기존 공개 사이트에는 배포하지 않았습니다.

## 반영 위치

- 설문 하단: 선택한 취향은 현재 브라우저 세션에 저장되며, 추천 요청 시 식사·알레르기 선택값이 서버에 전달되어 메뉴 조건 확인에 사용된다고 설명합니다. 기존 수정·건너뛰기 동작을 유지합니다.
- AI 음식 추천·유행 음식 질문 입력창: 질문이 외부 AI 서비스 Claude로 전달된다고 설명하고 이름·전화번호 등 개인정보를 입력하지 않도록 안내합니다. 각 입력창은 `aria-describedby`로 안내 문구와 연결됩니다.
- 도움말: AI 음식 추천과 유행 음식 설명은 연결되어 있으며, 주문·결제·배달은 시뮬레이션이라고 설명합니다. 주문 화면의 이름·전화번호는 AI 요청에 자동 첨부하지 않는다는 점과 식단·알레르기 선택이 식품 안전을 보장하지 않는다는 점도 안내합니다.

영어·일본어·중국어에 동일한 내용을 적용했습니다. 언어를 바꿔 설문을 저장하면 AI 안내와 도움말도 해당 언어를 사용하며, 저장하지 않고 닫거나 건너뛰면 기존 언어를 유지합니다.

## 현재 정보 흐름과 구현

`public/ai-ui.js`는 사용자가 추천을 요청할 때 저장된 설문 객체(`lang`, `country`, `diet`, `avoid`, `spice`, `allergies`, `other`)를 서버에 전달합니다. 자유 입력 질문이 있으면 질문도 함께 보냅니다. `server/api.mjs`는 설문 조건을 서버에서 검증·반영하며, 자유 입력 질문을 Claude로 분석합니다. 유행 음식 질문은 질문·선택 언어 등을 서버로 보내고, Claude는 검색된 근거와 함께 답변을 생성·검사합니다. 설문 전체를 그대로 Claude에 전달하는 구조는 아닙니다. 사용자가 질문에 직접 넣은 개인정보는 질문과 함께 전달될 수 있으므로 입력 주의 문구를 표시합니다.

이 변경은 안내 문구를 현재 동작에 맞춘 것입니다. 서버의 기존 요청·응답 캐시나 외부 서비스의 보관 방식에 대해 “브라우저 밖에는 전혀 저장되지 않는다” 또는 “즉시 삭제된다”는 약속을 추가하지 않습니다.

문구와 도움말은 `public/privacy-notices.js`에 분리했습니다. 원본 `public/app.js`, `public/style.css` 및 메인 화면 구조는 그대로입니다. `server/page.html`에는 해당 스크립트와 AI 입력 안내 문단을 연결했습니다. 기존 추천 규칙·요청 내용·결제 동작은 변경하지 않았습니다.

## 확인

원본 디자인 파일 153개 및 메인 화면 구조 유지, 화면·서버 메뉴 버전 일치를 확인했습니다. 브라우저에서는 세 언어의 설문 4단계, 언어 저장·건너뛰기, 도움말, 두 AI 입력창 안내와 입력 접근성 연결, 수동 실행 시에만 전송되는 기존 요청 내용을 확인합니다. 브라우저 검증의 AI 요청은 테스트 응답으로 대체하여 유료 모델을 호출하지 않습니다.
